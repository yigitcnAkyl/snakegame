🐍 Classic Snake Game (Unity 2D)A polished, grid-based 2D Snake game developed in Unity with C#. The project showcases clean event-driven architecture, smooth directional rotation, screen wrap-around mechanics, persistent high scores, and a responsive UI built with TextMeshPro.✨ FeaturesGrid Movement Mechanics: Reliable, discrete tile-based navigation preventing input dashing and unexpected self-collision bugs.Dynamic Body & Corner Smoothing: Smooth directional transitions with interpolated corner angle calculations ($45^\circ$ bends) between segments.Screen Wrap-Around: Seamless edge wrapping (LevelGrid boundary validation) allowing the snake to traverse boundaries without dying.Accurate Collision & Death Sequence: Pre-move collision anticipation ensuring the snake head faces the point of impact rather than clipping into its own body.Decoupled Event Architecture: Clean separation of logic and presentation through C# events (OnDied, OnAteFood).Persistent High Score: Saves the top score across play sessions using PlayerPrefs.Game Over & Restart UI: Full-screen overlay featuring the current run score, all-time record, and one-click/hotkey (Space / R) replay.🎮 ControlsActionKey / InputMove UpUp ArrowMove DownDown ArrowMove LeftLeft ArrowMove RightRight ArrowRestart GameSpace / R or Click Restart Button🛠️ Architecture & Scripts OverviewSnake.cs: Handles discrete grid stepping, inputs, direction clamping (preventing $180^\circ$ instant self-reversals), body segment generation, and collision checks.LevelGrid.cs: Validates grid limits (wrap-around logic), randomizes food placement, and confirms whether food has been consumed.Score.cs: Static global score manager tracking the active session tally and persisting high scores to disk via PlayerPrefs.ScoreUI.cs: Listens to Snake.OnAteFood and Snake.OnDied events to update and toggle the in-game display.GameOverWindow.cs: Displays the summary screen on death, presenting active score vs. high score, and listens for replay inputs.🚀 Getting StartedPrerequisitesUnity Editor: Version 2021.3 LTS or
